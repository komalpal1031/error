What is HTML?

+

HTML stands for HyperText Markup Language. It is used to create the basic structure and content of a website.

What is CSS?

+

CSS stands for Cascading Style Sheets. It is used to design HTML elements and control colors, spacing, layouts, fonts and responsive website design.

What is JavaScript?

+

JavaScript is a programming language used to make websites interactive. It can respond to clicks, change HTML, validate forms and perform many other tasks.

What is Flexbox?

+

Flexbox is a CSS layout system that helps developers arrange elements in rows or columns and control alignment, spacing and positioning.

What is CSS Grid?

+

CSS Grid is a powerful two-dimensional layout system. It allows developers to create complex rows and columns for modern website layouts.

What is DOM?

+

DOM stands for Document Object Model. JavaScript uses the DOM to find, change, add or remove HTML elements from a webpage.
